# Campus Lumen 文档

Last updated: 2026-10-29

Campus Lumen 帮大学生跨机构发现、理解和处理机会。中期 demo 让所有机会类型共用“探索 → 发现 → 处理”流程；导师是内容最深的示例，AI 整理使用明确标注的模拟服务。社区、账号、真实模型、跨设备同步和生产部署不在中期范围。
