## 下一步采集方法

将导师／课题组、学位项目、年度招生通知分开记录并关联。同一机构目录不算多个完成的导师样本。最终约 20–30 条目标指具体导师／课题组，当前这九个来源入口不代表已达到该目标。

对每条样本整理研究内容、所属单位、参与／申请途径、公开要求与下一步准备。补齐本校与外校、研究所、香港和美国的具体人物及多学科样本；只记录公开的工作联系入口，不采集无关个人信息。

需求验证重点是减少逐站查找、帮助理解研究方向和形成候选名单。招生名额、经费、指导风格和申请成功率若没有相应证据，保持未知，不由论文数或机构名气生成结论。
