# 可行性分析报告

Last updated: 2026-10-29

状态：中期分析。本文依据当前实现、Git 历史和 2026-10-29 的实际走查，回答中期演示是否可行；验收口径见[中期验收标准](acceptance.md)，执行结果见[测试报告](test-report.md)。

## 1. 项目与分析边界

Campus Lumen 是面向大学生个人使用的跨机构机会探索工具。所有机会类型共用“探索 → 发现 → 处理”流程，选导师内容最深，其他类型复用整理入口。中期 AI 整理是明确标注的本地模拟服务，不是真实模型。

可行性判断针对本地中期 demo，不外推为公开服务、全量资料库、真实 AI 质量或实际学生收益已经可行。

## 2. 技术可行性

- 当前系统已形成 React/Primer 单页应用、同源 `localStorage` 多会话、Rust/Axum 无状态 API、OpenAPI 与 TypeScript 客户端的可运行链路，结构见[概要设计](../architecture/overview.md)。
- 发现服务有整轮 30 秒、最多 5 个正文、6 次读取、48 次 HTTP 请求、每页 1 MB 等边界；客户端等待 35 秒，进程并发 2，见[API 契约](../architecture/api-contracts.md)。
- 2026-10-29 走查两次直读成功：`https://jzuming.github.io/` 取得 4,421 字，`https://www.cis.mpg.de/internships/` 取得 16,000 字并保存为依据。关键词“程序分析 导师”返回验证页，另有正文读取失败和限定目录无匹配；这是已验证的技术风险，不是假设。
- 模拟整理链路已覆盖选择发送、等待、返回、错误和送达不明；它只并列和引用依据文本，不能证明真实模型的推理质量。现有请求契约已限定最多 60 条公开依据和 10 条用户显式选择的私人片段，可作为真实模型适配边界。

| 关键风险 | 当前证据 | 可选缓解 |
| --- | --- | --- |
| 公网关键词搜索被验证页阻断 | 10 月 29 日实时关键词走查失败；两次已知官网直读成功 | 接入付费搜索 API；或维护经核对的官网目录并只做目录内查询；现场保留失败状态，不用回放冒充实时 |
| 可读站点范围窄 | 当前只读取允许范围内的公开静态 UTF-8 HTML；PDF、登录页和依赖 JavaScript 的页面不在范围内 | 按业务需要扩充 host/path allowlist，同时保留现有 DNS/IP 校验、私网地址拒绝、重定向复核、大小/时间/次数上限；新增站点逐个测试 |
| 真实模型的质量、费用和数据处理未验证 | 中期服务无模型、无外部网络、无持久化；输出只是确定性文本整理 | 通过现有 selected-content 契约接入供应商适配器；继续默认不选私人片段、回显发送内容、保留来源引用，并另做质量与隐私验收 |
| 浏览器本地状态依赖固定 origin | 会话仅存于当前浏览器 `localStorage` | 演示固定浏览器/profile/origin；若公开发布，再设计导出、备份或同步，而不是把本地存储当作长期可靠存储 |

**判断：**本地中期演示技术上可行。任意关键词的公网发现和真实模型整理尚不能作为无降级方案的运行前提。

## 3. 数据与来源可行性

现有 7 位导师、3 个实习候选和 26 条跨 8 类机会／入口资料，足够走通有限演示。来源、取得时间、历史状态、未知项和私人记录已有分别表达；历史招募不显示为当前开放。当前没有可交付的具名独立指导经历样本，因此产品显示缺口、待问事项和公开了解路径，不生成评价。

**判断：**现有资料足以演示发现、比较、补查和整理，不足以作全量覆盖、实时开放状态或人物质量评价。

## 4. 经济与成本可行性

中期 demo 不调用收费模型或收费搜索 API，直接费用边界是已有开发机、网络和现场环境，不等于长期“零成本”。下面只估算两个未来调用选项，不含托管、监控、人工核对、税费和汇率换算。

### 4.1 真实 LLM 整理

按现有契约的单次上限估算：60 条依据 × 800 字符 + 问题 300 字符 + 10 条私人片段 × 500 字符 = 53,300 字符。为覆盖中英文混合、字段标签和序列化开销，采用 **1 字符≈1 token，并向上取整为 54,000 输入 tokens**；输出假设约 1,000 tokens。实际费用应以上线前 tokenizer 实测为准。

2026-10-29 读取的 [DeepSeek 官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 列出高峰时段、缓存未命中的价格：`deepseek-flash` 输入 2 元/百万 tokens、输出 8 元/百万 tokens；`deepseek-v4-pro` 输入 9 元/百万 tokens、输出 27 元/百万 tokens。以下用较保守的高峰、缓存未命中价：

| 模型 | 单次整理 | 1,000 次 | 100 名学生 × 20 次/月（2,000 次） |
| --- | ---: | ---: | ---: |
| DeepSeek Flash | 0.116 元 | 116 元 | 232 元 |
| DeepSeek V4 Pro | 0.513 元 | 513 元 | 1,026 元 |

计算式分别为 `0.054×输入单价 + 0.001×输出单价`。官方页列出的空闲时段价为高峰的一半，但预算不依赖该优惠。

同日也读取了 [Kimi 官方模型计费页](https://platform.moonshot.cn/docs/pricing/chat)；可读内容确认按输入/输出 token 计费及 1 MTok = 1,000,000 tokens，但未提供可核对的当前数字价格表，因此不写 Kimi 金额。

### 4.2 付费搜索 API

2026-10-29 读取的 [Brave Search API 官方价格页](https://brave.com/search/api/) 列出 Search Plan 为 **5 美元/1,000 次请求**。按每次搜索一个 query、一次计费请求估算：

| 用量 | 费用 |
| --- | ---: |
| 1 次搜索 | 0.005 美元 |
| 1,000 次搜索 | 5 美元 |
| 100 名学生 × 20 次/月（2,000 次） | 10 美元 |

搜索 API 只能提高搜索结果入口的稳定性，不能替代正文读取、来源核对或取得第三方内容的转载权。

### 4.3 开发投入

Git 历史从 2026-07-06 首次提交到 2026-10-29 中期集成为 115 个日历日；产品于 2026-09-22 重置，重置后到中期为 37 个日历日。提交作者名包括 `August`、`114August514` 和 `jasonxu-cell`。这些记录只能说明日历跨度和参与者标识；仓库没有可靠工时记录，不能换算人时、人月或人工成本。

**判断：**本地中期演示的调用成本可控；按当前上限请求估算，未来真实 LLM 与搜索 API 的纯调用费量级可计算，但公开服务的总拥有成本尚不能判定。

## 5. 运行与维护可行性

演示使用本地 Axum API 与 Vite Web，从固定 `http://127.0.0.1:5173` 打开。API 不保存探索会话；主题、决定和私人记录只在同一浏览器 profile 与 origin 的 `localStorage` 中。长期负责人、更新周期、服务级别、异议入口、备份和公开部署均未确定。

**判断：**单机、单浏览器演示可以运行；长期公开运营和多人维护尚无成立条件。

## 8. 方案比较

| 方案 | 优点 | 代价／风险 | 中期取舍 |
| --- | --- | --- | --- |
| 原站＋搜索／AI＋笔记 | 无需建设新产品，灵活 | 跨来源关联仍由个人承担，负担未测 | 保留为有效替代与对照 |
| 入口导航 | 单次查询简单，维护相对容易 | 不能独立支持深度比较 | 纳入资料库和轻任务终点 |
| 精选机会资料库 | 便于发现、查看条件与原文 | 选源、去重、更新有成本 | 作为已有资料基础，不以数量宣称价值 |
| 有限资料＋按需关联比较 | 支持发现、比较、来源与私人判断 | 解释和关系维护成本较高，资料可能不完整 | **当前采用** |
| 全平台自动推荐＋推送／进度 | 可设想支持持续跟踪 | 数据、个性化、权限、运营和返回需求证据不足 | 中期不采用 |

## 9. 局限

- 10 月 29 日走查由建设者自行执行，不是学生试用；没有 USTC 用户研究、收益测量或长期返回观察，截图也未归档进仓库。
- 7 位导师画像由 AI 子代理编写，尚无人类逐条复核；入口比较单元格只引用入口 URL，不能据此认为每个比较陈述都已被独立核验。
- 资料库搜索使用 CJK bigram，会过度匹配；实时关键词搜索又被验证页阻断，两者都限制发现结果的可靠性。
- 成本表是按契约上限和官网标价计算的参数模型，不是账单；没有纳入缓存命中、折扣、税费、汇率、失败重试、正文抓取、托管、监控或人工审核。
- 公开运营所需的内容更新责任、个人信息处理依据、版权/平台条款审查、异议流程和真实 AI 供应商条款尚未确定。

**结论：**Campus Lumen 在有限资料、官网直读、固定本地环境和明确模拟 AI 的边界内，已经达到中期 demo 的技术、数据、短期成本和排期可行性。公网关键词发现、真实模型、公开运营、长期维护和学生收益尚不具备同等证据，不能从本次中期结果外推。
