# 用户手册

Last updated: 2026-10-31

状态：中期 demo 手册。最终操作名称以实际页面和[测试报告](test-report.md)为准。模拟、真实 AI、合成、已有资料与实时读取必须按页面标签解释。

## 1. 本地运行

要求：Bun、Rust stable；API readiness 仍需要本机 PostgreSQL 配置，具体环境变量见 `.env.example`。

词元计划是可选 provider：在启动 API 的服务端环境设置 `USTC_LLM_API_KEY`，可用 `USTC_LLM_MODEL` 改写默认模型 `deepseek-v4-flash-ascend`。未配置时界面禁用该选项，模拟服务仍可用。**不得把真实 Key 写入或提交到仓库、前端代码、截图或日志。**

在仓库根目录分别打开终端：

```bash
bun install
bun run dev:api
```

```bash
bun run dev:web
```

浏览器打开：

```text
http://127.0.0.1:5173
```

请始终使用该 origin；不要在 `localhost` 与 `127.0.0.1`、不同端口或不同浏览器 profile 之间切换，否则本地探索记录不会共享。

## 2. 支持环境

- 桌面：Chrome、Edge、Firefox 当前稳定版。
- 响应式检查：1280px 桌面与 390px 移动视口。
- 持久化：只保证同一浏览器 profile、同一 `http://127.0.0.1:5173` origin。
- 中期是本地 Web demo；不承诺公网、旧浏览器、原生移动端、跨设备同步或 Tauri 桌面端。

## 3. 基本使用

1. 从首页输入问题，或打开资料库直接搜索入口。
2. 在“探索”调整类型、目的和条件；不填写完整画像也可继续。
3. 在“发现”先看已有资料；只有点击联网查找或直读官方页才会访问外部来源。
4. 查看运行状态、来源和取得时间；“已有资料”“本次取得”“待查线索”“演示回放”含义不同。
5. 将有用对象加入当前会话的“处理”区，选择保留、待定或排除。
6. 仅选择同类对象比较；依据不足保持未知，可从未知项发起补查。
7. 点击“按问题整理差异（AI）”或“按问题整理当前视图（AI）”后，先检查发送内容并按次选择“模拟服务”或已配置的“词元计划”。个人理由和待问默认不选，只有勾选项会随请求发送。
8. 保存会话后，可在“我的探索”恢复。记录只在本浏览器，不是云端账号数据。
9. 资料库可不建会话直接打开原站；找到入口即可结束。

## 4. 状态与隐私提示

- **实时**：本次确实向 API 发起公开网页读取；成功与失败都照实显示。
- **已有资料**：仓库内审查过的快照或整理，不代表刚刚联网取得。
- **模拟／合成**：模拟整理、发现回放或合成数据用于演示状态机和隔离规则，不证明真实外部事实。
- **真实 AI**：词元计划结果显示平台与模型；一次成功返回不代表输出质量、平台保留规则、额度归属或团队 Key 政策已验证。
- 个人理由、待问和决定默认只在本浏览器。不要输入密码、token、私人联系方式或未经同意的真实学生资料。

## 演示脚本

以下 14 步覆盖“探索 → 发现 → 处理”。演示前打开 `#/demo`，用页面顶部的按钮载入两个合成示例主题（名称带“（合成示例）”，可一键清除），并按需设置 AI 模拟结果（正常 / 延迟 3 秒 / 超时 / 服务错误）和联网查找方式（实时或演示回放）。每一步都标明模式：实时 / 已有资料 / 本地 / 模拟 / 回放 / 真实 AI。

1. **从首页写下问题，开始探索**（本地）——打开 `#/explore?stage=explore&q=想找本科阶段能参与的 AI 系统方向短期科研`。不建主题也能进入“① 探索”；问题、类型和条件可以随时修改，不会自动联网。
2. **在“② 发现”中查看已有资料的匹配**（已有资料）——打开 `#/explore?stage=discover&q=AI 系统 短期科研`。每条标“已有资料”和采集日期，途径状态分“有依据 / 未知”；加入对象需要先保存为探索主题。
3. **直读一个官方页（江祖铭主页）**（实时）——打开 `#/item/zuming-jiang`，点击“直读官方页”。运行记录逐步显示读取、结果和结束状态；正文标“本次取得”和取得时间，可关联到江祖铭并保存为依据。失败会如实显示失败原因。
4. **载入两个合成示例主题，进入“③ 处理”**（本地）——在 `#/demo` 点击“载入两个合成示例主题”，进入“③ 处理”。对象表可按保留 / 待定 / 排除切换；宋卓然的职称冲突集中提示，保留待核。
5. **比较江祖铭与宋卓然，切换到“短期参与”**（已有资料）——打开 `#/compare?ids=zuming-jiang,zhuoran-song&p=short-term`。同一行比较同一个问题；“未提及”不等于不接收，不打分；每格可以查看依据原文。
6. **在“仍需确认”行对宋卓然补查**（实时）——在同一路径 `#/compare?ids=zuming-jiang,zhuoran-song&p=short-term` 的“仍需确认”行发起补查。查询预填当前问题和姓名；保存后该格显示“补查所得（日期）”。
7. **按问题整理差异，只勾选一条理由**（模拟）——在同一路径点击“按问题整理差异（AI）”，保留默认“模拟服务”。发送前列出公开依据和本主题的个人内容（默认不选）；返回后服务回显收到的条数，与勾选一致；结果标“模拟服务输出”。
8. **接收服务改选“词元计划”，再整理一次**（真实 AI）——服务端需先配置词元计划 Key。在同一确认框改选“中国科大大模型公共服务平台（词元计划）”；仍只发送列出的依据和勾选内容。返回结果标“AI 生成：平台 · 模型”，引用编号可回到来源；未配置时该选项不可选。2026-10-31 的两次实际等待为 58 秒和 35 秒，不把它们当作固定时长。
9. **把 AI 模拟设为“超时”，再发送一次**（模拟）——回到 `#/demo`，在“AI 整理（模拟服务）的结果”中选择“超时”，再以模拟服务发送。状态从“已发出，等待结果”变为“发送状态未确认，可能已发送”；停止等待不显示为已撤回。
10. **同一流程换一类：交流与暑校**（已有资料＋实时）——打开 `#/compare?ids=mpi-internship,ista-internship`。MPI 与 ISTA 的项目入口走同样的详情、比较和直读；比较维度换成概况、条件、支持与时间。
11. **资料库直达：搜“GPU”，打开原站**（已有资料）——打开 `#/library?q=GPU`。只查入口时搜到即可离开，不需要建主题；条目注明“可申请不等于获批”，GPU 等条件未确认的写明待核。
12. **切换到另一个合成主题，查看同一位导师**（本地）——打开 `#/sessions`。两个合成主题对江祖铭的理由各不相同，互不覆盖；删除一个主题不影响另一个。
13. **刷新页面**（本地）——刷新后回到上次打开的主题和阶段；记录只在这个浏览器的同一地址下恢复。
14. **开启发现回放“中止后迟到”，查找后点中止**（回放）——在 `#/demo` 把联网查找方式设为“演示回放：中止后迟到”，再打开 `#/explore?stage=discover&q=江祖铭 RA` 发起查找并点中止。已收到的一条保留，迟到的结果不写入；回放内容标“演示回放”且不能保存。

演示结束时说明：中期真实能力包括有限公开网页读取、浏览器本地会话，以及可选词元计划的真实调用；默认与回退仍是模拟服务。真实调用已走通并保存一次，但输出质量、平台日志／保留／删除规则、额度归属、团队 Key 政策、跨设备同步、公开部署、全量覆盖和学生收益均未声称完成。
