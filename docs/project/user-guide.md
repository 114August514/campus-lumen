# 用户手册

Last updated: 2026-10-29

状态：中期 demo 手册。界面仍在整合，最终操作名称以实际页面和[测试报告](test-report.md)为准。模拟、合成、已有资料与实时读取必须按页面标签解释。

## 1. 本地运行

要求：Bun、Rust stable；API readiness 仍需要本机 PostgreSQL 配置，具体环境变量见 `.env.example`。

在仓库根目录分别打开终端：

```bash
bun install
bun run dev:api
```

```bash
bun run dev:web
```

浏览器打开：

```text
http://127.0.0.1:5173
```

请始终使用该 origin；不要在 `localhost` 与 `127.0.0.1`、不同端口或不同浏览器 profile 之间切换，否则本地探索记录不会共享。

## 2. 支持环境

- 桌面：Chrome、Edge、Firefox 当前稳定版。
- 响应式检查：1280px 桌面与 390px 移动视口。
- 持久化：只保证同一浏览器 profile、同一 `http://127.0.0.1:5173` origin。
- 中期是本地 Web demo；不承诺公网、旧浏览器、原生移动端、跨设备同步或 Tauri 桌面端。

## 3. 基本使用

1. 从首页输入问题，或打开资料库直接搜索入口。
2. 在“探索”调整类型、目的和条件；不填写完整画像也可继续。
3. 在“发现”先看已有资料；只有点击联网查找或直读官方页才会访问外部来源。
4. 查看运行状态、来源和取得时间；“已有资料”“本次取得”“待查线索”“演示回放”含义不同。
5. 将有用对象加入当前会话的“处理”区，选择保留、待定或排除。
6. 仅选择同类对象比较；依据不足保持未知，可从未知项发起补查。
7. “按问题整理（模拟）”会先展示发送内容。个人理由和待问默认不选，只有勾选项会随请求发送。
8. 保存会话后，可在“我的探索”恢复。记录只在本浏览器，不是云端账号数据。
9. 资料库可不建会话直接打开原站；找到入口即可结束。

## 4. 状态与隐私提示

- **实时**：本次确实向 API 发起公开网页读取；成功与失败都照实显示。
- **已有资料**：仓库内审查过的快照或整理，不代表刚刚联网取得。
- **模拟／合成**：只用于演示状态机和隔离规则，不证明真实外部服务或事实。
- **送达不明**：请求可能已经发出，但浏览器没有确认结果；停止等待不等于撤回。
- 个人理由、待问和决定默认只在本浏览器。不要输入密码、token、私人联系方式或未经同意的真实学生资料。

## 演示脚本

以下约 10 步覆盖“探索 → 发现 → 处理”。演示前打开 `#/demo`，确认每项的“实时 / 已有资料 / 模拟 / 合成”标签。

1. **统一流程起点（已有资料）**：从首页输入“想找本科阶段能参与的 AI 系统方向短期科研”，类型可先不限；进入同一会话的“探索”，说明导师、实习、交流、资源等都使用同一套三阶段流程。
2. **导师发现（已有资料）**：进入“发现”，查看江祖铭与宋卓然；指出来源、采集时间、历史／未知状态，不能把整理摘要说成实时正文。
3. **官网直读（实时）**：选择江祖铭的官方页 `https://jzuming.github.io/`，点击“直读官方页”；展示实际运行记录、正文节选和取得时间。若网络或读取失败，保留失败并继续，不开启回放冒充成功。
4. **比较与补查（已有资料＋可选实时）**：把江祖铭、宋卓然加入处理并比较，切换研究／短期参与视角；指出每格依据和“仍需确认”。从一个未知项发起补查，结果回到对应候选。
5. **AI 整理与隐私（模拟）**：在当前会话为一个对象写一条合成理由，打开“按问题整理（模拟）”；只勾选这一条，确认发送汇总不含其他理由或会话，再发送。展示结果的来源引用、“模拟服务”与“需核实”标签。
6. **送达不明（模拟）**：回到“演示路线”，选择 AI “超时”选项，再发送一次；等待页面显示“发送状态未确认，可能已发送”，停止等待不显示成撤回，重试仍展示当前选择。
7. **双会话隔离（合成）**：载入两个名称带“（合成示例）”的会话，同一对象分别写不同理由；切换、刷新和删除其中一个，确认另一个的理由不变化。说明这只验证隔离，不是真实学生资料。
8. **第二、第三种类型（已有资料）**：新建“交流与暑校”会话，走一次探索、发现、加入处理和同类决定；再以“资源与支持”走同一流程，说明内容深度来自现有资料，不声称新增调研或当前开放。
9. **资料库直达（已有资料）**：打开资料库，搜索“文献”或“图书馆”，查看用途、权限／费用性质和注意事项，点击原站；强调无需创建会话、比较或完成准备任务。
10. **恢复与窄屏（本地＋走查）**：回到“我的探索”，打开最近会话并停在上次阶段；刷新页面确认恢复。把视口改为 390px，重复首页 → 会话 → 比较 → AI 确认，检查无横向页面滚动、候选名保留、导航可用。

演示结束时说明：中期真实能力是有限公开网页读取与浏览器本地会话；AI 为模拟服务；真实模型、跨设备同步、公开部署、全量覆盖和学生收益均未声称完成。
