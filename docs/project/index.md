## 当前口径

- 所有机会类型在前端共用“探索 → 发现 → 处理”流程；选导师是内容最深的示例，其他类型复用已有整理入口，资料深度不同。
- AI 整理默认使用界面明确标注的本地模拟服务；服务端配置 Key 后可在每次发送前改选中国科大词元计划，模拟服务仍是回退。
- 实时读取、既有资料、模拟回放和合成数据分别标识，不互相替代验收证据。
- 已知主要缺口：按关键词发现新对象不可靠；导师档案未经人工核对；没有本校用户调研和学生试用；验收为开发者自评。详见测试报告和过程回顾。
