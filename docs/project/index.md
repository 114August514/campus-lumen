## 当前口径

- 所有机会类型在前端共用“探索 → 发现 → 处理”流程；选导师是内容最深的示例，其他类型复用已有整理入口，不据此宣称同等资料深度。
- 中期 AI 整理使用界面明确标注的本地模拟服务，不调用真实模型；真实模型接入不在中期范围。
- 实时读取、既有资料、模拟回放和合成数据必须分别标识，不能互相替代验收证据。
