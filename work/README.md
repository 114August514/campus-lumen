# 本地过程区

Last updated: 2026-10-22

草稿、调查笔记、临时脚本、截图和实验输出放在这里，避免散落到代码与正式文档中。目录职责与成果归档规则见[文件树与过程文件归属](../docs/engineering/repository-layout.md)。

按任务建目录即可，不要求每次工作都产生文件：

```text
work/
├── README.md
├── YYYY-MM-DD-task/
│   ├── notes.md             按需保留的过程笔记
│   └── ...                  该任务的草稿与实验输出
└── legacy/
    ├── notes/temp1.md       原 temp/ 下的历史草稿
    └── prototype/
        └── opportunities.html
```

只有本说明参与版本管理，其他内容默认忽略，不强制添加、不发布。这里的文件不会随 Git 克隆同步，不能成为源码、测试、构建或正式文档的必要依赖。

需要长期交接的结论提炼到正式文档；简短待办与已完成事实沿用 `docs/ai-log/`；可复用工具和已核对数据移入相应维护目录。原始聊天、逐步执行日志和反复修改的草稿留在此处，不整段复制到 AI 日志。

不保存秘密、凭据、认证画面或私人学生数据。任务结束后按需保留材料；清理已有文件前确认用途，不自动删除。
